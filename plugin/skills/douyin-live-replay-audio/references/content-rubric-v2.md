# 内容评分量表 v2

生效：2026-09-21。两项独立评分，不使用旧0—4级分数映射。

## 共同原则

- 原问题未直接回答、转资料、延后报价、引导私聊或建议看另一产品，可以是获客策略。单凭这些行为不扣分，也不自动加分；其效果在实际当班评论后留资中检验。
- 评价整段直播中的实质内容，含主动讲盘、实景带看、产品比较和客户交流；不要求每个评论都被直接解决。
- 客户利益、内容价值与现有互动/留资/小风车/静默指标各按自己的证据计算，不将有无留资重复作为这两项得分条件。
- 明显识别错字、字幕幻觉、字幕重复、背景插话和设备调整不据此扣主播表达分。待核素材不补零，不把模型识别概率视为真实识别准确率。
- 统计跨日期、同项目、同稳定person_id的内容；使用一致的取样与汇总方式。存下评分原话、录音位置、来源哈希、覆盖及未知项。完整文本特征统计与语义逐段复核分别标明。

## 价值讲透：1—5分，总分权重5%

只评价两个方面：客户利益讲清、解释具体有支撑。

原生分 = 1 + 客户利益分(0—2) + 具体支撑分(0—2)。百分制 = 原生分 / 5 ×100；综合分贡献 = 原生分。最低1分适用于有足够内容可评价的低水平表现，缺少素材用null。

|小项|0分|1分|2分|
|---|---|---|---|
|客户利益讲清|仅列配置、口号、好看或高端，未说明客户获得什么实用好处|指出宽敞、方便、省钱等利益，解释简略，作用关系仍较泛|说明具体居住、收纳、出行、支出或生活场景，并把产品特点与该好处连接起来|
|解释具体有支撑|仅笼统形容，无可辨的参数、场景、实物或比较|有个别事实、参数或例子，但与利益的关联、说明过程不充分|参数、具体使用示例、实景结构或对比能支撑解释；不要求每种证据同时出现|

|最终原生分|可复算的档位|
|---|---|
|1|两个小项均0；只有口号或配置名，没有清晰客户利益及支撑|
|2|一个小项1，另一个0；有零散利益或信息，但说明不足|
|3|两个小项均1，或一个2另一个0；利益与支撑已出现但未同时讲充分|
|4|一个小项2、另一个1；一侧清楚完整，另一侧还偏概括|
|5|两个小项均2；具体好处与解释依据形成清楚联系|

卖点数量、覆盖次数和讲述长短不直接决定该项得分。短的完整价值解释也可得5分。参数仅作为主播解释的内容证据，不自动升级为经过独立核实的项目事实。

## 表达组织：1—11分，总分权重11%

本项观察主播所讲内容的实际价值、文本可理解性、无用重复和语气词负担。原生分 = 1 + 有效内容(0—4) + 可理解性(0—2) + 内容推进(0—2) + 语气词控制(0—2)。百分制 = 原生分/11×100；综合分贡献 = 原生分。

### 有效内容（0—4）

|分值|明确锚点|
|---|---|
|0|观察内容无可辨的产品、价格、居住使用、位置配套或下一步实用信息|
|1|只有少量孤立信息，多为口号、欢迎、泛泛催促，难以形成产品认识|
|2|能获得基本产品或价格信息，解释深度有限，有效信息与套话混杂|
|3|提供多项可用于了解房源、使用空间、比较或采取下一步行动的信息，部分段落较泛或重复|
|4|连续讲述有充足的具体信息，围绕实景、使用方法、差异或选择持续展开；长度短也可达到|

获客步骤本身属于实用信息。一次清楚的资料获取或到访说明不因涉及小风车而扣分。不断重复相同步骤且不再增加信息，在内容推进项处理。

### 其余三个小项（各0—2）

|小项|0分|1分|2分|
|---|---|---|---|
|文本可理解性|可核原话经必要纠错后仍持续缺少明确对象/关系，难以形成可理解意思|大意可辨，但需要反复拼接，面积、产品或对象关系偶有不清|产品对象、数字含义、步骤或空间关系清楚，连续内容可跟随|
|内容推进与无用重复|同一短段反复回到相同信息，基本无新增内容，挤占大量实质讲述|有局部回环、铺垫或复述，但仍持续补充信息|每段信息有推进，复述用于总结、强调或照顾新进观众；无明显无效循环|
|语气词控制|在可核文本或原声中，“呃、嗯、那个、就是说、的话呢”等持续密集堆叠，明显打断有效信息|有可观察的口语填充，但大部分意思能连贯推进|足量保留原貌的文本/听音证明口语填充少且不干扰；单纯未识别到不构成满分证据|

- “的、呢、啊”不逐字机械罚分；保留正常口语表达、礼貌称呼、强调与必要过渡。
- 正常直播轮次的再次介绍不计无用重复；只在同一可核连续语境判断信息是否原地循环。连续相同ASR字幕先排除识别幻觉。
- 文本可理解性可以作为内容清晰程度的代理。真实ASR识别准确率须有人工逐字校对稿作参照，当前条件缺少该基准时不填准确率数值，不用ASR置信度替代。
- ASR可能删除语气词或增加重复。语气词不可充分观察时该子项为null、贡献范围0—2。需要阶段点估计时使用范围中点1，并明确标成文本阶段估计；这不等于认定主播应得1分，也不作为已核扣分。保留最终表达分上下界，音频校准后替换。

### 1—11分的解释与复算

最终分由上述四项相加；同一个总分可以有不同优缺点，复核时以分项和原话为准。下表给出一组明确的典型组合，按“有效内容/可理解性/内容推进/语气词”列示。

|最终分|典型分项组合|典型表现|
|---|---|---|
|1|0/0/0/0|无有效信息，持续难理解且重复填充严重|
|2|1/0/0/0|只有零散信息，表达障碍明显|
|3|1/1/0/0|少量内容大意可辨，循环和填充较重|
|4|2/1/0/0|基本产品信息存在，清晰度及推进较弱|
|5|2/2/0/0|基础信息清楚，但原地循环和填充负担重|
|6|2/2/1/0|基础内容清楚且有推进，语气词负担较重|
|7|2/2/1/1|基础内容清楚，有部分有效推进和口语冗余|
|8|3/2/1/1|多项实用信息清楚，局部重复或口语填充|
|9|4/2/1/1|具体信息丰富清楚，仍有部分冗余|
|10|4/2/2/1|具体信息丰富、推进顺畅，存在轻微口语填充|
|11|4/2/2/2|内容充足、清楚、持续推进，语气词控制有充分证据|

所有未知子项均保留可得范围；上表不用于把未知项固定补成典型组合。自动字符数、重复候选和语气词候选只能帮助定位原话，不能代替语义评分。
