# 主播身份与实际交接

## 证据与覆盖

先复用已确认的稳定人员ID与姓名—昵称关系，再检查本周自报和交接。身份来源分开保存：录音中明确自报、明确交接、运营当班说明、用户逐段确认、用户限定批次的排班授权。姓名、实际起止、来源及审核状态进入当周覆盖台账，逐场核对正式主播、跨盘支援和临时代播；人员表不证明本人已出播。

私人项目档案保存person_id、姓名与昵称、支援记录、证据时间和原文、确认片段及音频时钟。跨日同项目按person_id合并；跨项目沿用ID、分别计算项目表现。历史具体班次不套用于新周。

匿名说话人分段可用于定位声音变化和待核连续片段。实名由自报/昵称、交接语义和人工确认确定；不建立实名声纹注册表，不以声音生物特征把上周样本匹配到新周姓名，不把匿名簇当成实名确认。已确认昵称可用于其他明确自称该昵称的片段，昵称冲突保留待核。

## 交接边界

实际话术、交接语境和匿名声源变化优先于排班整点；迟到、提前接播按录音证据修正。排班用于定位核查位置，不能自动覆盖矛盾录音。同事短插话、走位、背景讲解和播放视频先核查连续语境，不能直接切成新主播。

保留起止与误差范围。用户确认一个点位只覆盖该点及有连续证据的讲述，不能推导整个交接精确秒数。批次按排班授权只覆盖所列编号。更新身份后增量重算受影响区间的时长、评论去重、留资归属和评分，已核分段ID保持稳定。

确有歧义时一次给编号、项目、日期时段和约35秒短试听；先查已有答复，避免重复确认。待确认片段保留匿名身份，其余采集、评论审核和评分继续推进。影响客资的边界给具体评论时间，原回答人和经营归属分别保存。

## 临时代播不足20分钟

按实际连续交接起止，严格不足20分钟的临时代播不计主播人数，也不纳入个人时长、互动、留资、评论后留资、价值、表达、小风车、静默和评分。20分钟整仍计入。常规班次重启、分块文件或录制缺口形成的短文件不能按临时代播排除。

保存排除区间、持续秒数、依据与关联评论/客资审计，不删除原始数据，不把排除客资分给邻接主播。判断材料不足时保留待核，不能以排除规则掩盖未完成身份工作。
