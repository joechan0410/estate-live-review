# 网页、MP3 与密码访问

## 项目部署配置

在用户当前授权范围内发布。先从当前项目工作目录读取 `deployment/README.md`（若项目采用小写则读 `deployment/readme.md`）、`deployment-state.json` 或 `deployment/state.json`，按其中引用定位 `web-login/` 和构建包装器。域名、服务名、远端目录、监听地址、运行时、认证模式及回退版本均以该项目已验证配置为准，不从其他项目复制。没有现成配置时先完成本地交付，部署目标由用户实际请求确定。

密码沿用项目服务器既有配置，插件与可分发文件不保存凭证或哈希。已有表单密码登录时，鉴权覆盖 HTML、JSON 和全部 MP3；未登录进入该项目登录页，认证服务故障应拒绝访问。新增域名、公开分享或改变访问范围必须来自当前任务授权。

旧系统采用表单登录以改善微信访问体验。各项目浏览器、手机、微信设备验证状态独立记录；模拟 User-Agent 或窄屏浏览器不能替代实际微信设备验证。

## 保留当前认证实现

- 保留服务端密码哈希，常规报告更新不重设密码。
- 依照当前项目配置检查认证服务、会话时长，以及 Secure、HttpOnly、SameSite cookie 设置。
- 保留 CSRF 与同源 Origin 校验，并核对 Referrer-Policy 与真实表单提交兼容性；变更后检查登录回路。
- 查明既有认证程序的运行时依赖；若使用 Python `crypt`，升级运行时前核对兼容性。
- 已采用表单鉴权的项目，不允许旧 Basic 配置覆盖当前入口；使用该项目包装部署器与保护检查。
- 报告版本更新只切换已核内容，保留当前域名配置、证书、压缩、认证服务和其他站点。

## 构建与发布核验

使用当前项目包装构建器，保留外置数据 JSON、media 和 clips 目录。原构建器重建 dist 后必须重新打包音频。HTML 不得有 base64 音频，大小上限 8 MiB；达到上限先排查文件内容。音频 `preload=none`，点击后加载，服务端支持 Range 和 206。

发布前核对文件数、字节、哈希、相对路径和覆盖清单；保留上一版目录和回退方法。发布后检查匿名登录页、错误密码、正确密码→报告→录音、JSON 和 MP3 匿名保护、Range 播放、项目切换、桌面/手机宽度及控制台。音频未变可复用既有解码与哈希证据。将实际配置和核验结果记录回项目部署状态，避免在插件内固化个人站点信息。

旧周报告验收与源分析完整度分别保存。认证密钥、完整客户标识、手机号、受限回放 URL 与个人声音档案不进入网页或可分发插件包。
