# 验收与持续执行

分析完成与采集、脚本运行、队列启动、语境准备、页面构建分别保存状态。持续推进可执行的未完成项；只有必要外部材料/登录/用户判断确实缺失时报告具体阻塞，并完成其余独立工作。任务复杂、处理慢、当前批次结束或生成阶段页都不构成整周完成。

## 逐项完成条件

|项|可核验的完成条件|
|---|---|
|场次与录音|与目标周期后台场次逐场对账；媒体覆盖、缺段、失败及延迟回放有记录；完整MP3逐文件全段解码、编码参数和时长核验通过|
|压缩交付|16 kbps、16 kHz、单声道；完整时轴与静默未裁切；新旧哈希/大小/时长差及全部引用可追溯；不将试听认可写成ASR/VAD等效|
|身份覆盖|正式、支援、临时代播逐段列出；录音自报/交接优先排班；匿名/待核区间不遗漏、不伪称实名全验证；严格不足20分钟临时代播按规则排除并保留审计|
|转写与语义|字幕冻结、长空白、首尾缺失已核；原文与纠错可追溯；模型候选、文本特征统计和逐条语义审核分别计数，缺覆盖明确|
|全量评论|每场右上角“评论分析”条数、人数、已留资标记与原评论对账；每条原评论有实际处置，全部有效评论有答法审核结果/待核原因；禁止首问、关键词、每人限额、交接或下播过滤|
|留资链|完整ID与带时间明细双向连接标记，保存未闭合差异；评论后在实际归属主播当班内提交才计成功，无秒数/30分钟或回复完成门槛；重复不多计，原回答人与末次评论经营归属分开|
|个人评分|同项目稳定person_id跨日合并；权重25/11/16/5/11/16/16总和100；核心1—5、表达1—11原生量表有依据；缺测不补0或满分；按综合总分排序|
|静默|严格>10秒计整段，10秒不计、10.1秒整段计；电梯/视频不豁免；仅有证据的录制缺口/技术故障排除；500秒/小时40分，严格>500为0，再乘16%|
|聚合看板|周、累计、月度均能显示个人总分/贡献/评价及问题和答法汇总；合并原始分子分母/时长后重算，不平均周分或取首周短评；真实日期切分并保留缺覆盖范围|
|网页交付|沿用已验收版式；03先评论回复与留资；总数、样本率、排名和来源复算一致；浏览器检查周期切换、项目/主播、折叠和音频，无相关运行错误；HTML≤8 MiB、无内嵌音频、全部引用存在|

有同项目同周后台同ID留资的纯问候/表情按用户例外保留有效评论，仍不虚构产品问题或答复。团队账号按ID整号剔除。后台定义或计数出现差异时保存双方值，不能补删原记录凑平。

连续静默由合格音频证据判断，不能把不连续的两个6秒拼成12秒。背景同事、视频人声与主播发声分开，VAD候选保留来源与复核覆盖。视频记录可用于解释声源或排除非主播价值口播，不能用于静默豁免。

听音评价必须有工具实际可读的音频或人工复核依据。播放按钮可点、ASR错字、录音附件被拒绝均不构成听音完成。没有到访/成交回执不报告这些结果；未观察到留资也不能直接证明某答法失败。

## 发布及结束回复

缺项未闭合时保存阶段报告、剩余队列和阻塞，禁止称定稿、全部已核或全量完成。每次可见结束提供已验证可访问、周期相符的实际报告预览链接与阶段；后台进度页不能代替报告。

发布需在用户当前授权范围内；保留原表单密码、HTTPS、报告/JSON/录音鉴权，验证匿名保护和已登录录音Range。只改本地或沉淀规则不自动触发上线。新周仅复用配置、人员ID、有效知识和程序结构，不复用旧周人工评价、客户结果、班次或静默秒数。
