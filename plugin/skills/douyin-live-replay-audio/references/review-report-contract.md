# 房产直播复盘口径

## 范围与可比较性

时区明确，逐场记录完整起止与媒体覆盖；跨零点按用户指定边界。场次观看人数、线索人数跨场相加称“场次人次”，除非有稳定合法标识完成去重。主播效率默认以可分析在岗秒数/3600为分母；同时展示分母、总数、每小时结果与小样本标记。

## 必须分开的指标

| 指标 | 定义 | 分母/限制 |
|---|---|---|
| 静默次数 | 每个连续无主播说话、时长严格>10秒的事件 | 不以字幕缺口推断；电梯、视频不豁免；仅有证据的录制缺口、技术性音频故障排除 |
| 静默时间 | 所有合格事件的完整秒数之和 | 同时列秒/小时、占在岗时间比例和最长一次 |
| 发声占比 | 音频中目标发声秒数/可分析在岗秒数 | 背景语音会使VAD高估；人工复核明确范围 |
| 引导轮次 | 组件名+操作，或明确点预约/授权等操作；连续同一轮指引合并 | 每小时；同段重复三次“点”仍为一轮 |
| 引导命中窗 | 命中上述规则的字幕窗口数 | 仅供审计，不冒充精确次数 |
| 小风车点击 | 平台组件点击次数 | 观众行为；与主播引导轮次分开 |
| 有效评论 | 客户需求、产品问题、异议、预约意向 | 排除团队；有同ID留资的纯问候/表情按最终例外保留 |
| 有效问题回复率 | 已逐条确认回复的问题数/已审阅有效问题数 | 自动匹配只叫候选，不计已确认回复 |
| 回复延迟 | 回复开始相对评论时间的差值 | 字幕仅有观察窗时给范围，不假装逐字时间 |
| 收割推进 | 是否给到相关资料、具体看房时间或预约授权步骤 | 是行为；实际留资由后台核实 |
| 有效评论客户留资率 | 本场有有效评论且被后台标为已留资的客户数/有效评论客户数 | 同一客户在本场的关联，未必由该评论引发 |
| 时段线索数 | 留资时间落在该时段的记录数 | 多次留资、跨场去重、边界不确定另列 |
| 核心价值讲透 | 具体卖点+证据/事实+客户利益，必要时说明适用条件 | 不因未讲所有卖点扣分 |
| 流畅度 | 经核音的中断、修补、无效重复与表达连贯性 | 字幕词频仅代理指标，不能替代核音 |

## 输出结构

1. 顶部周度/累计/月度与项目选择，标题日期同步；一次只展示一个项目，明细不再增加主播/日期筛选。
2. 主播分析：互动/留资对比、经营数据、评级、综合评价、录音、七维加权贡献。
3. 项目专属价值点覆盖：含小风车，1小时/2小时/总次数与合计。
4. 评论回复与留资优先，接客户最常问、同类答法比较；实际答法、同ID后续结果、建议及参考话术分开，完整明细可展开。
5. 最后折叠完整明细、静默事件、排除证据、身份边界与方法来源。

90秒讲透一个价值、180秒建立首轮核心认知均为可调整的管理观察窗口，不是通用行业达标线。使用用户最后确认的七维权重与阶段/最终评级规则。

用户最终选择：连续严格>10秒计完整静默区间，电梯、视频均不豁免；仅有证据的录制缺口、技术性音频故障排除，音频不裁剪静默。背景同事或视频讲解人声与主播本人说话分开，VAD候选需复核声源。静默按秒/小时分段计分，乘16%计入七项加权总分，主播按总分降序排名。

经营留资归属采用留资前最后评论的实际主播；原回答人、留资时主播与业务归属分别保存，详见comment-conversion.md。
