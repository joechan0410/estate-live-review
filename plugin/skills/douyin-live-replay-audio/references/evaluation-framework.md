# 主播七维评价与加权贡献

## 当前配置

唯一权重源为 `assets/scoring-policy.json`；项目有用户后续确认的版本时优先用项目配置。当前留资25、互动11、评论后留资16、价值讲透5、表达组织11、小风车16、静默16，总和100。旧15维、静默2%或5%、开场/视频交接评分已经被替代。A≥80，65≤B<80，C<65。

| 维度 | 分数来源 | 证据 |
|---|---|---|
| 留资 | 已核归属留资/小时，相对同项目同周正中位数映射70、封顶100 | 留资明细及末次评论归属审计 |
| 互动 | 有效评论人次/小时，同组正中位数映射70、封顶100 | 团队剔除、有效性、去重与在岗时间 |
| 评论后留资 | 同项目合格客户ID合并率为基线，5人强度先验收缩后映射70、封顶100 | 客户链、原始成功数/分母、实际主播当班边界 |
| 价值讲透 | 1—5分÷5×100，再乘5% | 基础1分＋客户利益0—2＋具体支撑0—2 |
| 表达组织 | 1—11分÷11×100，再乘11% | 基础1分＋有效内容0—4＋可理解性0—2＋无效重复控制0—2＋语气词控制0—2 |
| 小风车 | 60%已核引导质量分 + 40%同组引导/小时频次分；频次映射70、封顶100 | 连续操作合并轮次、质量样本和原文 |
| 静默 | 秒/小时按用户确认的分段线性曲线；0—30=100、60=95、120=85、180=75、300=60、500=40，严格>500=0；再乘16% | 连续严格>10秒计整段，电梯/视频不豁免，仅有证据的录制缺口和技术性音频故障排除；不裁剪静默 |

静默曲线相邻节点间线性插值；500秒/小时得40分，严格大于500秒/小时得0分。曲线和分级阈值是用户确认的本工作流管理配置，不宣称行业标准。全组某指标基线为0时缺乏相对区分依据，保留原始0及缺测说明，不任意给满分或整体0分。缺样本不等于表现差。

转换维度：校正率=(主播成功数+5×项目合并率)/(主播合格样本数+5)。合并率分母按合格的场次×主播×客户ID去重，分子同场同客户只计一次成功；项目合并成功数/合格分母取得，不能用主播百分比均值或直接相加重复客户。展示原始成功数/分母，校正率只参与评分。

## 阶段与最终评级

每位实名主播展示已核项。阶段分=已核加权贡献之和/已核权重×100；单维贡献=该维分×权重/100。缺项 contribution=null，范围为0至该维权重。总分可能范围为已核贡献至已核贡献+缺失权重。

不到2小时或10条已核问题标“短样本初评”；未知样本量不装作满足。阶段总分、等级、样本、可用权重和缺项同时保存。只有目标周完整、全部七项有合格证据后才给final_score/final_grade。页面构建、用户接受版式、当前稿件基本完成都不会自动把这些字段改成已全量核完。

展示“加权贡献”时必须说明每维为何得分、基线/样本、已贡献多少及缺项影响。不能只画彩条不解释，不能用无效0替代缺测。不同项目分别计算，主播按七项加权总分降序排名，不按留资单项排名，绝不按姓名调分或固化往期排名。

评分入口必须读取 `silence_score_curve`、节点与严格截止值；仅实现旧线性扣分的入口不得用于当前评分。`score_hosts.py`只应用已审输入，不执行录音判断或客户匹配。大华现有周报优先复用基准周的评分构建入口；该入口含当周人工短评，复制至新周时必须替换人工评价来源并清除旧周数据，不能沿用旧结论。

## 综合评价

格式：`姓名｜等级`，`【优点】`1—2句，`【缺点】`1—2句。经营表现优先：留资/小时、有效评论人次/小时、已核评论后留资、小风车引导和静默。选一两项最有解释力的数据。缺点给直接可操作的一条改进；不另设“增加/减少”栏。

声音状态、亲和力、咬字、重音停连可补充，来源应为实际听音或用户人工复核。只收到总体文字意见时更新诊断和短评，不凭空生成精确数值。人工复核原文、项目周期、时间、来源、旧值保留；未提及某项不能当作无问题。不能从静默推断正在回消息或工作态度。

## 2026-09-21 生效内容量表

新分数须复核实际讲述，旧分不能直接缩放冒充新审。详细1—5与1—11档位见 [内容评分量表](content-rubric-v2.md)。回避直答可为获客策略，内容分不按原问题是否解决扣分，也不重复奖励留资或小风车结果。文本识别程度仅是代理观测，ASR软件错字、背景串音、缺失不直接扣主播分；未做人工参考逐字对齐不输出识别准确率。语气词可能被ASR删去，缺观测保留范围与文本阶段标识。全量文本特征和语义实际评阅覆盖分别记录。
